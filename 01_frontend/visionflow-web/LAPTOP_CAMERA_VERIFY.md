# VisionFlow 노트북 웹캠 AI 추론 검증

## 화면 구분

- `/mobile-camera`: 노트북 웹캠 영상만 AI 서버로 전송하는 빠른 검증 화면
- `/mobile-flight`: PC 수동 텔레메트리와 웹캠을 같은 비행 세션으로 전송하는 통합 검증 화면
- `/cameras`: 기존 주소 호환을 위해 `/mobile-camera`로 자동 이동

## 실행 조건

다음 서비스가 먼저 실행되어 있어야 합니다.

- 프론트엔드: `http://localhost:3000`
- 백엔드: `http://localhost:8080`
- AI 서버: `http://localhost:8000`

Docker 통합 실행을 사용한다면 프로젝트 루트에서 다음 명령으로 상태를 확인합니다.

```bat
docker compose --env-file .env.docker ps
```

## 노트북 카메라 검증

1. 브라우저에서 `http://localhost:3000/mobile-camera`를 엽니다.
2. 연결할 드론을 선택합니다.
3. 카메라는 `전면 카메라 · 노트북 권장`을 선택합니다.
4. 브라우저의 카메라 권한 요청을 허용합니다.
5. `카메라 전송 시작`을 누릅니다.
6. 미리보기가 나오고 `화면 전송`, `AI 수신` 프레임 수가 증가하는지 확인합니다.
7. AI 추론 결과는 기존 AI 분석 화면과 이벤트·스냅샷 API에서 확인합니다.

노트북의 `localhost` 접속은 일반적으로 별도 HTTPS 인증서 없이 카메라 권한을 사용할 수 있습니다. 스마트폰 LAN 접속은 신뢰된 HTTPS가 필요하며 별도 검증 대상으로 유지합니다.

## 장애 판별

- 드론 목록을 가져오지 못함: 백엔드와 프론트엔드 드론 프록시 상태 확인
- `AI 영상 입력 서버에 연결할 수 없습니다`: AI 서버가 8000 포트에서 실행 중인지 확인
- 프레임은 증가하지만 AI 수신이 0: `/api/ai/ingest/status`와 AI 서버 로그 확인
- 카메라 권한 거부: 브라우저 주소 표시줄의 사이트 권한에서 카메라를 허용한 뒤 새로고침
