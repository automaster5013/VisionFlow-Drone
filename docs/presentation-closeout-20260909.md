# 2026.09.09 발표 준비 마감 기록

## 현재 결론

발표 기준 기능을 동결하고 최종 PPT와 제출 영상을 제작했습니다. 이후 최종 발표를 완료했으며, 공개 운영 서비스와 배포 결과도 별도로 확인했습니다. 이 문서는 09.09까지의 발표 준비 작업 기록이며 현재 서버 가동 상태를 보장하는 실시간 점검표가 아닙니다.

## 구현·통합 검증

- AWS Next.js 웹·Spring Boot API·MySQL과 로컬 GPU FastAPI/YOLO/OpenCV AI를 연결하는 하이브리드 구성입니다.
- 발표 입력은 준비된 더미영상과 가상 텔레메트리입니다. AI 추론·서버 저장·조회는 실제 처리 흐름이며, 실기체 비행 시험은 아닙니다.
- 09.09 02:57:14~02:57:55 KST의 짧은 세션에서 영상 프레임 수락 94회, 좌표 25개, AI 이벤트 4건, 탐지 객체 기록 8개를 확인했습니다. 이벤트 수는 고유 사람 수나 정확도가 아닙니다.
- 서버 일시정지 02:57:29~02:57:42(13초)를 기록하고 품질 진단의 수신 공백과 구분했습니다.
- VFQ-1.1.0 평가 100점의 서버 저장·재조회를 확인했습니다. 데이터 흐름 규칙 기반 점수이며 AI 정확도나 비행 안전 인증 점수가 아닙니다.
- 사람 박스·라벨은 보호구보다 뒤에 표시하고, 안전모 미착용 중앙 경고는 천천히 깜빡이도록 보완했습니다. 내부 helmet은 hardhat, head는 no-hardhat에 대응합니다.

## 원거리 탐지·PPE 데이터: 완료와 미완료

기존 S1 가중치의 무결성을 확인하고 VisDrone 검증 이미지 24장을 동일 조건으로 비교했습니다. 입력 960, confidence 0.25, IoU ≥ 0.5, 작은 정답 박스 면적 <1,024 px² 조건입니다. 사람 정답 631개 중 작은 사람 529개에서 COCO는 140개(26.5%), S1은 245개(46.3%)를 찾았습니다. 차이는 +19.8%p입니다. 무시 영역 등의 공식 평가 조건을 완전히 처리한 전체 평가가 아니므로 Precision·mAP·PPE 정확도를 주장하지 않습니다.

건설현장 시연 영상 표본에서는 S1의 사람 탐지가 감소했습니다. 후보 매핑·해상도 비교는 운영 승격 근거가 충분하지 않아 기존 모델 구성을 유지했습니다. 이번 발표 준비에서 새 학습과 운영 모델 교체를 완료하지 않았습니다.

원본 PPE 데이터셋은 저장소 외부에서 확인했습니다. 현재 train/valid/test 라벨에서 선언된 person 클래스의 주석이 없었고, helmet/head 의미 및 중복 이미지 라벨 검수가 필요합니다. 현재 라벨 상태가 과거 학습 시점의 상태와 같다는 보장은 없습니다. 기존 별도 사람 탐지 모델을 유지합니다. 반사띠가 있는 파란 작업복도 vest로 포함하는 정의를 정했지만, 해당 정의의 추가 학습·정식 GT 승인·성능 검증은 완료하지 않았습니다. 일부 비파괴 검토 산출물은 정식 학습 데이터와 구분합니다.
