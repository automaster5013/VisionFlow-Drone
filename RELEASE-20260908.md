# Validated presentation runtime — 2026-09-08

This release preserves the currently deployed frontend and local CUDA inference images.
Frontend: public HTTPS QR pairing, login help contrast, mobile-flight session card contrast.
AI: actual person detections from an auxiliary COCO model, PPE-first annotation order,
no synthetic person boxes, and a centered Korean no-hardhat warning fading every 2 seconds.

## Runtime configuration

- AI_MODEL_PATH=/app/models/best.pt
- AI_PERSON_MODEL_PATH=/app/models/yolo26m.pt
- AI_PERSON_CONFIDENCE=0.25
- AI_NO_HARDHAT_WARNING=true
- AI_IMAGE_SIZE=640
- AI_DEVICE=0
- Model files are mounted separately; weights and credentials are not included in Git.
- AI status reports PPE_WITH_PERSON_DETECTOR: this is two models producing four output classes.
- Public frontend stream path: /api/ai/stream/annotated.
- Repository compose.release.yaml also expects a backend tag; this release publishes frontend
  and AI only. Keep the existing backend image when applying these two component updates.

## Presentation video

scripts/visionflow-presentation-feeder.py is the deployed 15 FPS wall-clock feeder.
It expects /tmp/presentation-dummy.mp4 and VISIONFLOW_AI_INTERNAL_KEY from the runtime
configuration. It skips old frames to maintain 1x playback. Video is excluded from Git;
the preserved frontend image contains the existing user-provided presentation video.
The AI image does not contain model weights or that video.

## Verification and remaining work

Frontend production build and TypeScript passed. AI annotation regression tests: 16 passed.
Four video samples at 2, 15, 39, and 60 seconds detected 1, 1, 7, and 2 persons respectively.
The 60-second sample produced all four classes. Full warning fade was checked at five
phases, including complete disappearance. GPU inference after warm-up was about 31–45 ms.

Smartphone end-to-end testing, valid-session AI event persistence (earlier HTTP 404),
and distinguishing manual telemetry from actual MOBILE_SENSOR values remain open.
Do not treat this release as validation of those unfinished integration paths.
